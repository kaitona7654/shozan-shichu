# note投稿ガイド：第1記事「日干10タイプ」

## 📝 投稿手順（5分）

### 1. note にログイン
https://note.com/ にアクセス → 「kaito」アカウントでログイン

### 2. 新規記事作成
右上の **「投稿」ボタン → テキスト** を選択

### 3. タイトル設定
以下をコピペ：

```
【初心者向け】血液型より深い「日干10タイプ」── 象山流四柱推命でわかる自分の本質
```

文字数：47文字（noteは100文字以内推奨）

### 4. 本文貼り付け
`02_日干10タイプ_note版.md` の内容をコピー → noteエディタに貼り付け

⚠️ **重要**：マークダウン記法は **noteエディタが自動変換** します。表組み・見出し・太字・絵文字すべて反映されます。

### 5. アイキャッチ画像
**option A：シンプル文字画像（Canvaで5分作成）**
- サイズ：1280×670px
- 背景：和風（紺色 or 白地に金）
- 文字：「日干10タイプ」「四柱推命入門」
- フォント：明朝体 or 楷書体（和の雰囲気）

**option B：Unsplashの無料画像**
- 検索キーワード：「japanese calligraphy」「kanji」「zen」「nature」
- おすすめ：太陽・大木・海など自然をモチーフにした写真

**option C：絵文字組み合わせ画像**
- 「🌳☀️🌊⚔️💎」のような10タイプを表す絵文字を並べる

### 6. タグ設定（5つまで）

以下を推奨（noteのタグは検索流入に直結）：

```
#四柱推命
#象山流
#占い
#自己分析
#日干
```

代替案：
- `#四柱推命入門` `#開運` `#占い好きさんと繋がりたい` `#note初心者`

### 7. カテゴリ設定
**「スピリチュアル」** または **「コラム」**

### 8. 価格設定
**「無料公開」を選択**（第1記事は集客用）

将来的に有料化したい場合：
- 全体無料、特定セクションを「有料部分」に設定可能
- 「気をつけて」で終わる占いは三流 セクションを有料にする手もあり

### 9. 公開ボタン
- 「下書き保存」で一旦保存推奨
- スマホでプレビュー確認（noteアプリ）
- 問題なければ **「公開する」**

### 10. SNS拡散
公開後すぐに：

**X（Twitter）投稿テンプレ**：
```
ブログ更新しました📝

【初心者向け】血液型より深い「日干10タイプ」
── 象山流四柱推命でわかる自分の本質

血液型診断より2.5倍深い10タイプ診断。
あなたは何タイプ？

[noteのURL]

#四柱推命 #占い好きさんと繋がりたい
```

**ハッシュタグ戦略**：
- `#占い好きさんと繋がりたい`（占い系コミュニティ）
- `#自己分析`（自己理解層）
- `#四柱推命`（コアファン）
- `#象山流`（差別化）
