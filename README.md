# 象山流四柱推命

生年月日（時刻・名前・性別もあれば）から、**象山流四柱推命**（田邊象山創始）の鑑定文を生成するアプリ。**Webサイト版（Streamlit）** が主軸、**LINE Bot** は資産として併存。

竹本泰祥氏（象山流）による実物の鑑定書を出力フォーマットの範とし、命式・吉神・空亡・調候・身強身弱・大運・年廻り・性格・適職・**開運法**・**起名学評価**までを Claude API で生成する。

**ビジネスモデル**: 3段階フリーミアム
- 無料: 命式表 + 性格傾向
- 完全鑑定: ¥1,500（全9セクション、単発購入）
- 月額会員: ¥980/月（再鑑定無制限）

## 象山流とは

田邊象山（1928-2015）が興した日本独自の四柱推命流派。

- **核心**: 命式解釈で終わらず、**開運法**（具体的行動アドバイス）まで導く
- **思想**: 生年月日は偶然ではなく**先祖の意思**が働いて選ばれたもの
- **特徴**: 生時不明でも生年月日のみで鑑定可能、刑・冲・害や支合・三合に独自解釈
- **8分野**: 家相・方位・年廻り・相性・**命名（起名学）**・病気・お祓い・**家系因縁**

本Botは **命式解釈＋命名（起名学）＋大運＋年廻り** の4分野を扱う。

| 入力 | 鑑定範囲 |
|---|---|
| `1976/5/4` | 命式（時柱なし）＋鑑定文 |

| `1976/5/4 4 中井利幸 男` | ＋**起名学評価**（漢字五行論） |

複数行・改行区切りも可。

## Web版（Streamlit）の手順 ←主軸

### 1. Anthropic API キー取得

1. https://console.anthropic.com/ で API key 作成
2. Settings → Billing で **$5以上をチャージ**

### 2. ローカル動作確認

```bash
cd ~/scripts/shichu_line_bot
cp .env.example .env
# .env を編集して ANTHROPIC_API_KEY=sk-ant-api03-... を貼り付け
./run_web.sh
# → http://localhost:8501 が自動で開く
```

1. このディレクトリを GitHub にプッシュ（プライベートリポジトリ可）

3. **「New app」** → リポジトリ選択、`web_app.py` を Main file に指定
4. **「Advanced settings」** → Secrets に `.streamlit/secrets.toml.example` の内容を貼り付け、`ANTHROPIC_API_KEY` を実値に
5. Deploy → 数分で `https://<your-app>.streamlit.app` が発行される

### 4. note や X で告知


## LINE Bot版の手順（オプション）

### 1. LINE Developers でチャネル作成

1. https://developers.line.biz/console/ にログイン
2. プロバイダー作成 → 「Messaging API」チャネルを新規作成
3. **チャネルシークレット** と **チャネルアクセストークン（長期）** を発行
4. 「応答メッセージ」オフ、「Webhook」オン

### 2. Claude API キー取得

1. https://console.anthropic.com/ にログイン
2. Settings → API Keys → Create Key
3. クレジット残高を確認（最低 $5 で開始可）

ANTHROPIC_API_KEY が未設定でも命式は返るが、鑑定文は出ない。

### 3. 環境変数設定

```bash
cp .env.example .env
# .env に LINE 資格情報と ANTHROPIC_API_KEY を記入
```

### 4. 起動

```bash
./run_local.sh
# → http://localhost:8000 で待受
```

別ターミナルで：

```bash
brew install ngrok
ngrok http 8000
# 表示される https URL/callback を LINE Webhook URL に設定
```

## Claude API コストとモデル選定

`ANTHROPIC_MODEL` 環境変数で切替（既定 `claude-opus-4-8`）。

| モデル | 入力 $/1M | 出力 $/1M | 1鑑定あたり目安 |
|---|---:|---:|---:|
| claude-opus-4-8（既定） | $5.00 | $25.00 | 約 $0.07〜0.12 |
| claude-sonnet-4-6 | $3.00 | $15.00 | 約 $0.04〜0.07 |
| claude-haiku-4-5 | $1.00 | $5.00 | 約 $0.01〜0.03 |

**プロンプトキャッシュ**: システムプロンプト（5773トークン）に `cache_control: ephemeral`。同じシステムプロンプトで連続リクエスト時、2回目以降は ~0.1× コストで読まれる（5分TTL）。

**ローカルキャッシュ**: 同じ命式＋名前＋性別の組み合わせには決定論的に同じ鑑定文を返す（`cache/{ハッシュ}.txt`）。クリアは `rm -rf cache/`。

## 鑑定文の構成

象山流の9セクション構成（竹本氏鑑定書と年廻り資料を範とする）：

1. **命式概要** — 四柱と特徴的配置
2. **五行バランスと吉神** — 用神・喜神・忌神・吉神の意味
3. **性格傾向** — 日干と通変から
4. **才能・適職** — 月柱・時柱から具体的職業
5. **大運の流れ** — 現在と次の10年
6. **今年〜近未来の年廻り** — 1年単位の運気段階と行動指針
7. **開運法（象山流の真髄）** — 具体的行動アドバイス3-5項目
8. **起名学評価**（名前ありの時のみ）— 漢字の部首・字源から五行分類
9. **家系・先祖からのメッセージ** — 象山流特有の家系因縁観

### 年廻りの12段階（十二運ベース）

| 十二運 | 年廻りキーワード | 性質 |
|---|---|---|
| 長生 | 開拓・新たな門出 | 種を蒔く |
| 沐浴 | 浮気・油断 | 華やかだが注意 |
| 冠帯 | 精算・充実 | 形になる |
| 建禄 | 健康・決定 | 意志決定の年 |
| 帝旺 | 成功・人気 | 頂点期 |
| 衰 | 落下・転換 | 切り替え時 |
| 病 | 古きを捨てる | 整理・断捨離 |
| 死 | ミステリー・内省 | 内面と向き合う |
| 墓 | 地点・蓄積 | 谷、守りに徹する |
| 絶 | 新規スタート・再生 | 殻を破る |
| 胎 | 再開・再会 | 新しい縁の芽 |
| 養 | 整える・育てる | 基盤作り |

## 法務メモ

- 占い系サービスは **景表法・特商法表記** が必須（有料化時）
- 健康・恋愛・金運の **断定的表現はNG**（システムプロンプトで禁止）
- 個人情報（生年月日・名前）は **取得目的の明示・最小保存** を守る
- 鑑定文の末尾に「参考目的」の免責文を必ず付与
